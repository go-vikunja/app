# Roadmap

Steps 1 to 42 are built, except the ones listed below: the release itself (37d), the four planned after 1.0 and the two dropped ones; 18, 19 and 36g are built but still in review. Each entry of the [decision log](decisions.md) names the step that took it. This page lists only what is left. The full plan, with every step, how the steps were reviewed, the milestones and the dated notes on each change, stays in git: `git show c2bf10d:docs/roadmap.md`. After the move the rows after 1.0 become GitHub issues, and this file can go.
