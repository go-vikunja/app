# Roadmap

Steps 1 to 46 are built, except the ones listed below: the fixes from the code review of 2026-11-23 (47a to 47i, the owner picks their order), the release itself (37d), the four planned after 1.0 and the two dropped ones; 19 is built but still in review until the iOS device test. The [decision log](decisions.md) holds the decisions that still apply, by topic. This page lists only what is left. The full plan, with every step, how the steps were reviewed, the milestones and the dated notes on each change, stays in git: `git show c2bf10d:docs/roadmap.md`. After the move the rows after 1.0 become GitHub issues, and this file can go.
