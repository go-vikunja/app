Konto löschen

Rurana hat keine eigenen Konten. Dein Konto liegt auf dem Vikunja-Server, bei dem du dich angemeldet hast, und dort liegen auch deine Daten. Ich als Entwickler von Rurana habe keine davon.

In der App

  1. Öffne im Tab „Konto“ die Kontoeinstellungen.
  2. Tippe ganz unten auf „Konto löschen“. Rurana erklärt, was passiert, und öffnet im Browser die Seite deines Servers, auf der du dein Konto löschst.
  3. Bestätige dort. Hat dein Konto ein Passwort, fragt die Seite danach.
  4. Dein Server schickt dir per E-Mail einen Link, mit dem du das Löschen bestätigst. Drei Tage nach deiner Bestätigung löscht er dein Konto. Bis dahin kannst du es dir anders überlegen: Der Tab „Konto“ zeigt das Datum mit „Löschung abbrechen“.

Ohne die App geht das genauso im Web: Öffne in der Vikunja-Web-App deines Servers die Einstellungen und lösche dort dein Konto.

Was gelöscht wird

Vikunja löscht dein Konto zusammen mit allen Projekten und Aufgaben, die dir gehören; was du mit anderen geteilt hast, geht an sie über. Ob der Server darüber hinaus etwas aufbewahrt, etwa in seinen Backups, und wie lange, hängt davon ab, wer ihn betreibt; frag dort nach.

Um das Konto auch von deinem Gerät zu entfernen, melde dich im Tab „Konto“ davon ab, wie unten beschrieben.

Wenn dein Server es nicht erlaubt

Manche Server erlauben nicht, Konten in der App zu löschen; Rurana weist dich dann darauf hin. Verschickt ein Server keine E-Mails, kommt die Bestätigung nie an. Bitte in beiden Fällen die Person, die den Server betreut, dein Konto zu löschen.

Die öffentliche Demo

Bitte lösche das gemeinsame Konto der öffentlichen Demo auf try.vikunja.io nicht: Andere Besucher nutzen es, und die Bestätigung geht an eine E-Mail-Adresse, die du nicht lesen kannst. Der Demo-Server wird in unregelmäßigen Abständen zurückgesetzt.

Ein Konto nur von diesem Gerät entfernen

Um ein Konto aus Rurana zu entfernen, es auf dem Server aber zu behalten, tippe ganz unten im Tab „Konto“ auf „Abmelden“ (bei mehreren Konten „Von diesem Konto abmelden“). Deine anderen Konten stehen im Tab „Konto“ unter „Konten“; öffne das Menü daneben und wähle „Entfernen“. Als Gast über einen geteilten Link tippst du auf „Gastzugang entfernen“. Rurana löscht dann die Kopie deiner Daten, die Kommentarentwürfe, den Inhalt der Widgets, die Benachrichtigungen und die Tokens dieses Kontos vom Gerät, wie es die Datenschutzerklärung beschreibt.
